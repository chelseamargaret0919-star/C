### **Canteen Card System -- The CCS #**

&#x09;The objective of this program is to allow easier access to history, balance, loans, and other transactions while also allowing students to manage their spendings better.



\-=Features=-



* *Simple Menu screens*
* *Fast and efficient responses*
* *Program is compact*



\-=Usage=-



**Calculation of Transactions**



* *Input your choices and personal information such as User ID and Password*
* *Each function has a different menu depending on the class you choose*
* *The ability to add, loan, and subtract differs from each class*
* *Choice to exit is given after*



**History of Recent Transactions**



* *The ability to check recent transactions throughout different classes*
* *Shows date, amount, and name of items bought*
* *(Note: This will only show the most recent transactions)*
* *Choice to exit is given after*
